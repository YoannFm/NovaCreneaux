# Historique des versions

Cet historique est produit à partir des étiquettes de version du dépôt git. Pour chaque version, il donne la date, le titre de la version, l'ampleur des changements et les évolutions de la base de données qu'elle apporte. Les notes complètes de chaque version sont sur la page Releases du dépôt GitHub.

Les versions suivent la forme `MAJEUR.MINEUR.CORRECTIF` : le deuxième nombre augmente pour une nouveauté, le troisième pour une correction.
